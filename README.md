# MedEcho

A family member photographs a medication instruction sheet. MedEcho calls the older adult in English or Persian, asks them to explain their medicines in their own words, grades each item with quoted evidence, re-teaches only what was missed using the sheet's exact wording, and checks again 48 hours later. The family receives a summary with audio of anything that did not stick.

MedEcho's voice can only say fixed phrases and verbatim text from the family-confirmed sheet. No language model output ever reaches the speaker.
